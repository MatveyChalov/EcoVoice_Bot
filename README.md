# 🌿 EcoVoice Bot — умный эко-помощник по снижению углеродного следа

Telegram-бот для хакатона, который помогает людям уменьшать личный углеродный
след с помощью **ИИ-анализа привычек**, **компьютерного зрения** (фото товаров
и чеков) и **голосовых рекомендаций**.

Бот умеет **говорить голосом** 🎙️ и **«видеть»** 📸: пришли ему вопрос об
экологии или фотографию покупки — он проанализирует это через ИИ и ответит
текстом + аудиосообщением.

## 🏗️ Стек технологий

| Слой | Технология | Назначение |
|------|-----------|------------|
| **Язык** | Python 3.10+ | Основной язык разработки |
| **Telegram API** | [aiogram 3](https://docs.aiogram.dev) | Асинхронная работа с Telegram Bot API |
| **Синтез речи** | [edge-tts](https://github.com/rany2/edge-tts) | Генерация русского голоса (Svetlana) |
| **Аудио-конвертация** | ffmpeg + libopus | Конвертация MP3 → OGG/Opus (формат voice) |
| **ИИ + Компьютерное зрение** | Google Gemini (OpenAI-совместимый API) | Текст (LLM) + изображения (vision LLM) |
| **Конфигурация** | python-dotenv | Загрузка секретов из `.env` |
| **Запуск (локально)** | uv / venv | Управление зависимостями |
| **Запуск (облако)** | Google Colab | Бесплатный запуск без установки |

**Почему aiogram, а не telebot:** aiogram 3 — асинхронный, корректно отправляет
голосовые через `send_voice` с файловыми объектами и поддерживает статусы
«печатает» / «записывает голосовое» (`send_chat_action`).

**Почему edge-tts:** лучшее качество русского синтеза речи среди бесплатных
решений, точный голос `ru-RU-SvetlanaNeural`, высокая скорость.

**Почему Gemini:** бесплатный тариф в AI Studio, отличное качество русского
языка и сильная vision-модель (Flash умеет и тексты, и картинки одной моделью) —
идеально для хакатона.

## 🏛️ Архитектура

```
                    ┌───────────────────────┐
                    │      Telegram         │
                    │   (пользователь)      │
                    └──────────┬────────────┘
                               │  Bot API
                    ┌──────────▼────────────┐
                    │        bot.py         │  ← обработка команд,
                    │  (aiogram Dispatcher) │     текста и фото
                    └───┬──────────────┬────┘
                        │              │
              ┌─────────▼───┐   ┌──────▼─────────┐
              │ ai_service  │   │ voice_service  │
              │ (Gemini API)│   │ (edge-tts)     │
              │  text/image │   │  text→ogg      │
              └─────────┬───┘   └──────┬─────────┘
                        │              │
                    ┌───▼──────────────▼───┐
                    │   Временные файлы     │
                    │      temp/            │  ← автоматически удаляются
                    └───────────────────────┘

Поток ответа на сообщение:
  1. Пользователь шлёт текст или фото.
  2. bot.py показывает статус «записывает голосовое».
  3. ai_service.py вызывает Gemini и получает ответ/вердикт.
  4. voice_service.py синтезирует речь и конвертирует в OGG/Opus.
  5. bot.py отправляет ответ текстом + голосовым сообщением.
  6. Временные аудио и фото удаляются (finally).
```

## 🚀 Быстрый старт

### Способ 1: Локально на Windows

**Требования:**
- Python 3.10+ (рекомендуется 3.11/3.12)
- [ffmpeg](https://ffmpeg.org) в PATH (для голосовых)
- Токен бота от [@BotFather](https://t.me/BotFather)
- Ключ API от [Google AI Studio](https://aistudio.google.com)

**Шаги:**

```powershell
# 1. Перейти в папку проекта
cd C:\Users\User\Desktop\eco_voice_bot

# 2. Создать виртуальное окружение (через uv — быстро и надёжно)
uv venv --python 3.12 .venv

# 3. Активировать окружение
.venv\Scripts\activate

# 4. Установить зависимости
uv pip install -r requirements.txt

# 5. Проверить ffmpeg
ffmpeg -version
# Если нет — установить:
winget install --id Gyan.FFmpeg -e

# 6. Заполнить .env (см. ниже)

# 7. Запустить
python bot.py
```

Альтернатива активации через классический `python -m venv .venv` (если нет uv).

### Способ 2: Google Colab (быстро, без установок)

Идеально для хакатон-демо — всё работает в браузере, ничего ставить не нужно.

1. Откройte **colab.research.google.com**
2. **Файл → Загрузить блокнот** → выберите `EcoVoice_Bot.ipynb`
3. **Runtime → Change runtime type** → `None` (CPU)
4. Выполните ячейки по порядку:
   - **Ячейка 1** — установка `ffmpeg` + `libopus` + Python-пакетов (~1 мин)
   - **Ячейки 2–3** — загрузка функций ИИ, голоса и логики бота
   - **Ячейка 4** — вставьте `BOT_TOKEN` и `AI_API_KEY`, запустите

> ⚠️ **Важно про Colab:** сессия живёт ограниченное время (~90 минут простоя).
> Бот работает, пока открыт блокнот. Для длительного деплоя используйте
> локальный запуск или VPS-хостинг.

## 🔑 Настройка .env

Создайте файл `.env` в корне проекта (для локального запуска):

```env
# Токен бота: получите у @BotFather в Telegram
BOT_TOKEN=123456789:AAE...твой_токен...

# Ключ ИИ (OpenAI-совместимый API). У нас — Google Gemini:
AI_API_KEY=AIza...твой_ключ...
AI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
AI_MODEL=gemini-3.8-flash
AI_VISION_MODEL=gemini-3.8-flash
```

> В **Colab-версии** токены вставляются прямо в последнюю ячейку блокнота
> (`BOT_TOKEN` и `AI_API_KEY`), файл `.env` не нужен.

## 🔧 Как это работает

### Обработка текста (эко-консультация)

1. Бот получает текстовое сообщение.
2. Показывает статус «🎙️ записывает голосовое».
3. `ai_service.analyze_text()` отправляет вопрос модели `llama-3.3-70b`
   с системным промптом эко-помощника.
4. `voice_service.text_to_voice()` синтезирует ответ голосом Светланы
   и конвертирует в OGG/Opus.
5. Бот шлёт ответ текстом **и** голосовым сообщением.
6. Временный аудиофайл удаляется.

### Обработка фото (сканирование покупки)

1. Бот получает фото и скачивает его во временную папку `temp/`.
2. `ai_service.analyze_image()` передаёт base64-код изображения vision-модели
   `llama-4-scout` вместе с заданием оценить экологичность.
3. Модель возвращает вердикт (оценка 0–10 + советы).
4. Бот отвечает текстом и голосом.
5. Временные файлы (фото и аудио) удаляются в `finally`.

### Обработка ошибок

Каждый обработчик обёрнут в `try-except-finally`:
- сбои сети → вежливое сообщение, бот продолжает работать;
- недоступность ИИ → пользователь узнаёт, что проверить ключ;
- сбой TTS → отвечает только текстом (голос некритичен);
- временные файлы удаляются гарантированно.

## 🐛 Возможные проблемы и решения

| Проблема | Причина | Решение |
|----------|---------|---------|
| `ModuleNotFoundError: aiogram` | Пакеты не установлены / не тот Python | Установи через `.venv`: `uv pip install -r requirements.txt` |
| Pylance: «не удается разрешить импорт» | VS Code смотрит не в `.venv` | `Ctrl+Shift+P → Python: Select Interpreter → .venv\Scripts\python.exe` |
| Бот запущен, но не голосовые | Нет `ffmpeg` | Установи ffmpeg (winget) — иначе придёт MP3 как аудио, не voice |
| «Не удалось получить ответ от ИИ» | Неверный ключ / закончилась квота Gemini | Проверь `AI_API_KEY`, лимиты на aistudio.google.com |
| Голос приходит как файл, а не voice | MP3 не сконвертирован в OGG/Opus | Убедись, что ffmpeg в PATH |
| Логи обрываются / бот молчит в Colab | Сессия Colab отключилась | Перезапусти рантайм и снова выполни ячейки |
| `externally-managed-environment` | Глобальный Python управляется uv/системой | НЕ ставь глобально. Создай `.venv` в проекте |

## 🌐 API-провайдеры

Проект использует **OpenAI-совместимый API**, поэтому легко переключается
между провайдерами — меняется только `.env`:

| Провайдер | `AI_BASE_URL` | Пример модели | Примечание |
|-----------|---------------|---------------|------------|
| **Google Gemini** (по умолчанию) | `https://generativelanguage.googleapis.com/v1beta/openai/` | `gemini-3.8-flash` | бесплатно, сильная vision |
| Groq | `https://api.groq.com/openai/v1` | `llama-3.3-70b-versatile` | очень быстро, бесплатно |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o` | платно, лидер качества |
| Любой совместимый | свой URL | своя модель | OpenAI-формат `/v1/chat/completions` |

> Для анализа фото можно использовать ту же модель (`gemini-3.8-flash`
> умеет зрение). Если провайдер требует отдельную vision-модель (например,
> Groq `llama-4-scout`) — задайте её в `AI_VISION_MODEL`.
